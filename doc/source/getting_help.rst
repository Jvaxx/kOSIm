Getting Help
============

Fork issues
-----------

For bugs, installation problems or changes specific to **kOS Improved**, use
`this fork's issue tracker <https://github.com/Jvaxx/kOSIm/issues>`_. Include the
fork version, KSP/OS/Proton versions, relevant mods, minimal reproduction steps
or script, expected/actual results and relevant log excerpts. Remove private
paths, credentials and personal save data before sharing logs.

Runtime validation is limited to Windows KSP 1.12.5.3190 under GE-Proton11-7
on Linux. Identify other environments explicitly; do not assume they were tested.

Upstream community
------------------

The `kOS subreddit <https://www.reddit.com/r/Kos/>`_ and upstream's
`Discord community <https://discord.gg/Hjsz7r9>`_ can be useful for general
kerboscript questions and examples. Explain that you are using a fork; those
communities are independent and do not provide kOSIM-specific support guarantees.

Do not send fork-only bugs to `upstream issues <https://github.com/KSP-KOS/KOS/issues>`_.
If you reproduce a problem on upstream too, identify the upstream build and
reproduction separately.
