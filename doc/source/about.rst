About kOS Improved and KerboScript
==================================

**kOS Improved (kOSIM)** is an independent fork of
`kOS <https://github.com/KSP-KOS/KOS>`_, the scriptable autopilot for Kerbal Space Program.
The source baseline is upstream kOS |upstream_release|. This manual describes the
fork, version |release|, while retaining the inherited language reference and tutorials.

The fork focuses on terminal reliability, editor/file safety, predictable input
ownership and a comfortable execution/debugging workflow. It is not an official
kOS release and is not maintained by the upstream team.

kOS was originally created by **Kevin Laity (Nivekk)** and developed by the
`kOS team and contributors <https://github.com/KSP-KOS/KOS/graphs/contributors>`_.
The fork's source and release history are at
`Jvaxx/kOSIm <https://github.com/Jvaxx/kOSIm>`_. See :ref:`copyright` for licensing.
