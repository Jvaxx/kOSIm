Contribute to kOS Improved
==========================

This manual belongs to **kOS Improved (kOSIM)**, an independent fork of kOS.
Send fork contributions to `Jvaxx/kOSIm <https://github.com/Jvaxx/kOSIm>`_,
against its ``master`` branch, not upstream's ``develop`` branch.

Read the `contribution guide <https://github.com/Jvaxx/kOSIm/blob/master/CONTRIBUTING.md>`_
for local setup, regression tests, compatibility rules and PR expectations.
Discuss major UI, language, compiler or runtime changes before implementing them.
Fork-specific bugs should be reported to the fork; upstream developers are not
responsible for reviewing or supporting these changes.

Editing this manual
-------------------

Edit the reStructuredText files under ``doc/source/`` and build HTML locally with
Python 3, Sphinx and the Read the Docs theme. Setup and commands are in
`doc/README.md <https://github.com/Jvaxx/kOSIm/blob/master/doc/README.md>`_.
The similarly named ``docs/`` directory contains developer notes, not this manual.
Do not commit generated HTML or publish it to upstream's documentation repositories.

The original documentation system was set up by
`Johann Goetz <https://github.com/theodoregoetz>`_. Upstream authorship and license
notices are retained; source contributions use the project's GPL v3 license.
